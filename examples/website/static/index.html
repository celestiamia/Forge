Getting Started

Forge is a systems programming language compiler (forgec) that targets x86_64 and x86_32 Linux.

It features a Python-like syntax with indentation-based blocks and full type inference.

Endpoints

  • /hello?name=YourName - Dynamic greeting
  • /api/status - Server status (JSON)
  • /api/random - Random number (JSON)
  • /counter - Server-side page counter
