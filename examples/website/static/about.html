Project Overview

Forge is a systems programming language compiler (forgec) that targets x86_64 and x86_32 Linux.

This website is a demonstration of a full web application written entirely in Forge, showcasing:

Features

  • HTTP server with routing
  • Dynamic page generation
  • Static file serving (HTML, CSS, JS)
  • JSON API endpoints
  • Multi-process concurrency (fork)
  • Proper HTTP headers and content types
