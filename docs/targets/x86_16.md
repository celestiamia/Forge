# x86_16 Boot Sector (Flat Binary)

16-bit real-mode target for bare-metal boot sectors.

## Target Triple

```
x86_16-boot
```

Not a Rust target - built using Forge's internal 16-bit assembler.

## Build

```bash
# Using x86_64 forgec compiler
./target/release/forgec examples/bootloader.dev -o boot.bin --target x86_16-boot

# Output: 512-byte flat binary with 0x55AA signature
```

## Architecture Details

| Property | Value |
|----------|-------|
| Architecture | 8086/8088 (real mode) |
| Format | Flat binary (raw bytes) |
| Endianness | Little |
| Pointer Size | 16-bit (segmented) |
| Code Origin | 0x7C00 |
| Signature | 0x55AA at offset 510 |

## Memory Model (Real Mode)

### Segmentation

```
Physical Address = Segment * 16 + Offset
```

Common segments:
- `0x0000` - IVT / BIOS Data Area
- `0x07C0` - Boot sector (loaded by BIOS)
- `0x0000` - Conventional memory (0-640K)

### Memory Map

```
0x00000 - 0x003FF   IVT (256 vectors × 4 bytes)
0x00400 - 0x004FF   BIOS Data Area
0x00500 - 0x07BFF   Free (conventional)
0x07C00 - 0x07DFF   Boot Sector (512 bytes)
0x07E00 - 0x9FFFF   Free
0xA0000 - 0xBFFFF   Video RAM
0xC0000 - 0xFFFFF   BIOS ROM
```

## Registers (16-bit)

| Register | Parts | Purpose |
|----------|-------|---------|
| AX | AH/AL | Accumulator |
| BX | BH/BL | Base |
| CX | CH/CL | Counter |
| DX | DH/DL | Data |
| SI | - | Source Index |
| DI | - | Destination Index |
| BP | - | Base Pointer |
| SP | - | Stack Pointer |
| CS | - | Code Segment |
| DS | - | Data Segment |
| SS | - | Stack Segment |
| ES | - | Extra Segment |
| IP | - | Instruction Pointer |
| FLAGS | - | Status Flags |

## Calling Convention

No standard ABI. Forge uses:
- Args passed in registers (AX, BX, CX, DX)
- Return in AX
- Caller-saved: AX, CX, DX
- Callee-saved: BX, SI, DI, BP

## BIOS Interrupts

| Interrupt | Function |
|-----------|----------|
| INT 10h | Video Services |
| INT 10h, AH=0Eh | Teletype Output |
| INT 13h | Disk Services |
| INT 16h | Keyboard Services |
| INT 16h, AH=00h | Read Keystroke |
| INT 19h | Bootstrap Loader |
| INT 1Ah | Time of Day |

## Boot Process

1. BIOS loads first sector (512 bytes) to 0x7C00
2. Jumps to 0x7C00 (CS=0, IP=0x7C00)
3. Boot sector sets up segments, stack
4. Loads next stage or kernel
5. Jumps to kernel entry point

## Output Format

Flat binary (raw bytes):
- No headers
- No sections
- Exactly 512 bytes
- Last 2 bytes: `0x55 0xAA` (boot signature)

```bash
# Output file
ls -la boot.bin
# -rw-r--r-- 1 user user 512 ...

# Verify signature
hexdump -C boot.bin | tail -2
# 000001fe  55 aa
```

## Example: Minimal Bootloader

```dev
@freestanding
pub def _start() -> void:
    # Set up segments
    unsafe:
        asm!("xor ax, ax")
        asm!("mov ds, ax")
        asm!("mov es, ax")
        asm!("mov ss, ax")
        asm!("mov sp, 0x7C00")
    
    puts("Hello, Forge bootloader!")
    _dev_halt()

def puts(msg: ptr[char]) -> void:
    unsafe:
        var p = msg
        var c = _dev_load_char(p)
        while c != 0:
            _dev_bios_teletype(c)
            p = p + 1
            c = _dev_load_char(p)

extern def _dev_bios_teletype(c: char) -> void
extern def _dev_load_char(p: ptr[char]) -> char
extern def _dev_halt() -> void
```

## Limitations

- 512-byte size limit (hard constraint)
- No heap, no GC
- No protection rings
- BIOS-dependent hardware access
- Single-threaded, no interrupts (by default)
- 16-bit arithmetic only

## Tips

1. **Keep it small**: Every byte counts
2. **Use BIOS**: Leverage INT 10h/13h/16h for I/O
3. **Avoid floats**: No FPU in real mode by default
4. **Manual segments**: Set DS/ES/SS explicitly
5. **Stack at top**: SP = 0x7C00 (grows down)
