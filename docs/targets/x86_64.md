# x86_64 Linux (ELF64)

Primary target for native 64-bit Linux applications.

## Target Triple

```
x86_64-unknown-linux-gnu
```

Rust toolchain: `x86_64-unknown-linux-gnu` (native)

## Build

```bash
# Native build
cargo build --release

# Or using forgec
./target/release/forgec input.dev -o output --target x86_64-unknown-linux-gnu
```

## Architecture Details

| Property | Value |
|----------|-------|
| Architecture | x86-64 (AMD64) |
| Format | ELF64 |
| Endianness | Little |
| Pointer Size | 64-bit |
| Page Size | 4 KiB |
| Calling Convention | System V AMD64 ABI |

## Registers

| Register | Purpose | Saved |
|----------|---------|-------|
| RAX | Return value / syscall # | Volatile |
| RDI | Arg 1 | Volatile |
| RSI | Arg 2 | Volatile |
| RDX | Arg 3 | Volatile |
| RCX | Arg 4 | Volatile |
| R8 | Arg 5 | Volatile |
| R9 | Arg 6 | Volatile |
| RBX | Callee-saved | Preserved |
| RBP | Frame pointer | Preserved |
| R12-R15 | Callee-saved | Preserved |
| RSP | Stack pointer | Preserved |
| RIP | Instruction pointer | N/A |

## Calling Convention

System V AMD64 ABI:
- First 6 integer args: RDI, RSI, RDX, RCX, R8, R9
- Additional args: on stack (right-to-left)
- Return: RAX (RDX for 128-bit)
- Stack: 16-byte aligned at call sites
- Red zone: 128 bytes below RSP (leaf functions)

## Stack Layout

```
High Address
├── Arguments (if > 6)
├── Return Address
├── Saved RBP
├── Local Variables
├── Red Zone (128 bytes)
└── RSP
Low Address
```

## Syscalls

Linux syscalls via `syscall` instruction:

| Syscall | Number | Registers |
|---------|--------|-----------|
| read | 0 | RDI=fd, RSI=buf, RDX=count |
| write | 1 | RDI=fd, RSI=buf, RDX=count |
| exit | 60 | RDI=code |
| mmap | 9 | RDI=addr, RSI=len, RDX=prot, R10=flags, R8=fd, R9=off |
| munmap | 11 | RDI=addr, RSI=len |
| socket | 41 | RDI=domain, RSI=type, RDX=protocol |
| connect | 42 | RDI=fd, RSI=addr, RDX=addrlen |

## Object Format

ELF64 with sections:
- `.text` - Executable code
- `.rodata` - Read-only data (strings, constants)
- `.data` - Initialized writable data
- `.bss` - Zero-initialized data (heap, GC)
- `.symtab` / `.strtab` - Symbols (stripped in release)

## Entry Point

Hosted mode: `_start` (runtime) → calls `main(argc, argv)`
- `argc` at `[rsp]`
- `argv` at `[rsp+8]`

Freestanding: Custom entry via `@freestanding` + `--freestanding` flag

## Memory Layout

```
0x0000000000000000 - 0x00007FFFFFFFFFFF  User space (canonical)
0x00007FFFFFFFFFFF - 0xFFFF800000000000  Non-canonical (hole)
0xFFFF800000000000 - 0xFFFFFFFFFFFFFFFF  Kernel space
```

Typical process layout:
```
0x0000000000400000  .text (executable)
0x0000000000600000  .data/.bss
0x00007FFFFFFFxxxx  Stack (grows down)
0x00007FFFF7xxxxxx  Shared libraries
```

## Runtime

Hosted runtime provides:
- `_start` entry point
- Stack top capture for GC
- SIGPIPE handling
- `main` invocation with argc/argv
- Exit handling

## Standard Library Support

Full support for all modules:
- `std.io` - Linux syscalls (write/read)
- `std.mem` - Optimized REP MOVSB/STOSB
- `std.string` - Pure software
- `std.math` - Integer + float (x87/SSE2)
- `std.alloc` - Bump (64 KiB) + GC (4 MiB)
- `std.fmt` - Software
- `std.volatile` - MFENCE/LFENCE/SFENCE
- `std.gc` - Conservative mark-and-sweep

## Float Support

Full x87/SSE2 support:
- `float32` / `float64`
- x87 FPU stack (legacy) + SSE2 registers (XMM0-15)
- ABI: floats in XMM0-7, return in XMM0

## Debugging

## Performance

- Native speed (direct machine code)
- No interpreter/JIT overhead
- No runtime overhead (minimal runtime)
- Optimizations: none yet (O0 equivalent)
